# München СТО — CRM система

Веб-приложение для управления небольшим автосервисом.
Два пользователя: **Владелец** (`owner`) и **Менеджер** (`manager`).

---

## Быстрый старт

### 1. Установка зависимостей

```bash
# Перейдите в папку backend
cd "Munchen Car repair/backend"

# Создайте виртуальное окружение (рекомендуется)
python3 -m venv venv
source venv/bin/activate          # macOS/Linux
# venv\Scripts\activate           # Windows

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка конфигурации

```bash
# Скопируйте шаблон
cp ../.env.example ../.env

# Откройте .env и замените SECRET_KEY на любую случайную строку
# Остальное можно оставить по умолчанию
```

### 3. Запуск

```bash
# Из папки backend/
python main.py
```

Приложение будет доступно по адресу: **http://localhost:8000**

---

## Доступ с других устройств в локальной сети СТО

Сервер по умолчанию слушает на `0.0.0.0:8000`, то есть доступен по локальному IP компьютера.

1. Узнайте IP компьютера: `ifconfig` (macOS/Linux) или `ipconfig` (Windows)
2. На других устройствах в сети откройте: `http://<IP-компьютера>:8000`

Пример: `http://192.168.1.100:8000`

## Функционал

### Для менеджера и владельца
- 👥 **Клиенты** — создание/редактирование/удаление клиентов
- 🚗 **Автомобили** — привязка авто к клиентам (марка, модель, гос. номер, VIN, год)
- 📋 **Заказ-наряды** — создание заказов с выбором клиента и авто
- ➕ **Работы** — добавление позиций в заказ с исполнителем и ценой
- 🔄 **Статусы** — смена статусов заказов и позиций (история сохраняется)
- 🔍 **Фильтры** — фильтрация заказов по статусу, дате, клиенту
- 👷 **Сотрудники** — карточка с перечнем назначенных работ и суммой

### Только для владельца
- 📊 **Аналитика** — выручка за период, разбивка по статусам, загрузка сотрудников, график по дням

## Миграция на PostgreSQL

1. Установите драйвер: `pip install psycopg2-binary`
2. Измените `DATABASE_URL` в `.env`:
   ```
   DATABASE_URL=postgresql://user:password@localhost/sto_db
   ```
3. Перезапустите сервер — таблицы создадутся автоматически.

> ORM-модели написаны без SQLite-специфики и переносятся без изменений.

## Деплой на хостинг

1. Установите зависимости на сервере
2. Настройте `.env` (укажите надёжный `SECRET_KEY`)
3. Запустите через **gunicorn** (рекомендуется для продакшна):
   ```bash
   pip install gunicorn
   gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000
   ```
4. Настройте nginx как reverse proxy (порт 80/443 → 8000)

## Будущее: WhatsApp уведомления (GreenAPI)

При смене статуса заказа на **«Готов»** вызывается функция `send_notification()` в `backend/notifications.py`.

Сейчас она только логирует вызов. Чтобы включить реальные уведомления:

1. Зарегистрируйтесь на [green-api.com](https://green-api.com)
2. Добавьте в `.env`:
   ```
   GREENAPI_INSTANCE_ID=your_instance_id
   GREENAPI_API_TOKEN=your_api_token
   ```
3. Раскомментируйте блок кода в `notifications.py`
